# Changelog

## 0.1.0 — release candidate, not published

- Self-hosted SMART EHR and standalone launch orchestration with separate upstream and application PKCE transactions.
- Application-first workspace, EHR platforms, vendor registrations, organizations, connections, installations and activations.
- Optional FHIR gateway, managed direct access, original credential access and explicit refresh ownership handoff.
- SMART Backend Services and authenticated CDS Hooks forwarding, with synthetic sample services.
- Local username/password or OIDC administration, scoped roles, actor-attributed audit records, first-owner bootstrap and offline password recovery.
- Health Compass patient sample with current/historical assessments and explicitly educational scoring.
- Production operations, security qualification and standalone SDK/release tooling are tracked in the accompanying operations, security and release documentation.
- SMART Flint Community License v1.0 and commercial agreement template, using the EASI JS distribution model. Third-party components retain their own licenses.

Additional real vendor/pathway qualification is deferred for joint testing. The existing compatibility evidence and known exceptions are recorded in [sample validation](docs/sample-validation.md). This candidate does not imply certification or universal EHR support.

Earlier development snapshots used SMARTBridge branding and were not versioned public releases in this workspace. See [branding and migration](docs/branding.md) for the explicit local upgrade process.
